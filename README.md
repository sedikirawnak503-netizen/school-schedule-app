# تطبيق جدول الحصص المدرسي 📚

تطبيق Android متكامل لإدارة جداول الحصص المدرسية باللغة العربية.

## الميزات ✨

- ✅ إضافة وحذف وتعديل الحصص
- ✅ إدارة الفصول والمعلمين والمواد
- ✅ البحث والتصفية
- ✅ إشعارات للحصص
- ✅ تصدير الجدول (PDF)
- ✅ تخزين البيانات محليًا (SQLite)
- ✅ واجهة رسومية سهلة الاستخدام

## المتطلبات 📋

- Android Studio
- Java 8 أو أحدث
- Android SDK 21 أو أحدث

## التثبيت 🔧

1. استنساخ المستودع:
```bash
git clone https://github.com/sedikirawnak503-netizen/school-schedule-app.git
cd school-schedule-app
```

2. افتح المشروع في Android Studio
3. قم بتثبيت التبعيات
4. شغل التطبيق على محاكي أو جهاز فعلي
